# Restaurant Booking Voice Agent - Frontend

React frontend for the AI-powered restaurant booking voice assistant.

## Features

- Voice input/output using Web Speech API
- Real-time conversation with AI agent
- Responsive design with modern UI
- Seamless API integration via proxy

## Setup

```bash
npm install
npm run dev
```

## Key Components

- **App.jsx**: Main component handling voice recognition, conversation state, and TTS
- **main.jsx**: React app entry point
- **vite.config.js**: Build configuration with API proxy

## Voice Features

- Speech-to-text for user input
- Text-to-speech for agent responses
- Conversation history management
- Error handling for unsupported browsers

Built with React 19 and Vite for optimal performance.
